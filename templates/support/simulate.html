How this is wired up

The codes live in the support_errorcode table and are served by /api/error-codes/. Every error page reads its wording from that same row (myproject/errors.py), so the reference page and the page you land on can never disagree, and support staff can reword an error in the Django admin without a deploy. The handlers are handler400, handler403, handler404 and handler500 in myproject/urls.py.
